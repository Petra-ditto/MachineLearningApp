This code covers the analysis of a dataset about loan applications and their approval. The dataset is loaded to the repository.

The _loan approval.py file provides the analysis of the dataset and creates a machine learning model we can use for prediction on our own.
1) Imports and data loading
2) EDA (basic statistics, missing values)
3) Preprocessing and train/test split
4) Logistic Regression (training, evaluation, coefficients)
5) Random Forest (training, evaluation, feature importance)
6) Utility: plots, save models

The _loan GUI.py creates a user interface where we can provide inputs and our model provides the verdict whether the loan should or should not be approved.
